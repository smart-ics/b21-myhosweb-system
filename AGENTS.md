# MYHOSWEB Agent Guide

Before doing any work in this repository:

1. Read `ARTIFACTS.md`.
2. Identify the authoritative artifact(s) relevant to the task.
3. Read those artifacts before making decisions or changes.
4. Follow the artifact relationships when additional knowledge is required.
5. Keep all affected knowledge synchronized.

`ARTIFACTS.md` is the primary navigation point for MYHOSWEB knowledge.

For Feature identity and Phase-0 Feature synchronization, use:
`project-management/phase-0-planning/MYHOSWEB-FEATURE-REGISTRY.md`
